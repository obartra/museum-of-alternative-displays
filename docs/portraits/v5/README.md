# Portraits, round 5

Open [index.html](index.html) directly in a browser. It works offline and makes no network requests until a source link is opened.

**32 review drawings:** 23 first portraits and nine retakes. **29 people remain pending.** 16 drawings are restricted to label size. Five follow pictures with a recorded reuse basis (including Walker’s reported grant awaiting recheck); 27 are studies from reference-only photographs. Four women have selected drawings: Bao, Hammond, Walker and Elma Farnsworth.

This is a review bundle. It does not activate portraits or change the 74 already on the site. Louis Brus’s fourth-round after drawing remains held; the existing study is untouched. Kara Walker’s original Vimeo licence could not be independently rechecked, so her drawing remains held for rights review. Studies carry uncertain publication rights; a new drawing is not a copyright clearance.

The per-person records describe the source pairing, age, feature/pose/clothing checks and remaining limits. Proportion measurements are rough 2-D screening, not face recognition or proof of likeness. Exact pose angles are not certified. All selected drawings still need museum review before activation.

Files: [manifest.json](manifest.json), [prompts.json](prompts.json), [STYLE.md](STYLE.md), [CREDITS.md](CREDITS.md), [PENDING.md](PENDING.md), [CHECKS.json](CHECKS.json), and the WebPs in people/. SHA256SUMS.txt covers every other file.

The compact package contains one selected export per person and the context needed to review it. It excludes source photographs, scanned PDFs, full PNG masters, discarded iterations, models and cumulative earlier packages. Those caused the previous archive bloat and are unnecessary for this review.

Inputs were checked on 22 November 2026. HTTP access failures are recorded as unresolved access, not evidence that a photograph does not exist. Original source pages may change; hashes identify the exact private inputs used.
